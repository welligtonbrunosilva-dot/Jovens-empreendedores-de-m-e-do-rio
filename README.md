# Jovens-empreendedores-de-mãe-do-rio
Plataforma digital Jovens Empreendedores de Mãe do Rio, criada para divulgar produtos e serviços de empreendedores locais, conectar vendedores e clientes e incentivar o empreendedorismo na comunidade. O site permite cadastrar anúncios, que passam por aprovação antes de serem publicados.
